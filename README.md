# בקרת בקשות ייצור

מערכת ווב לניהול, מעקב ובקרה על בקשות ייצור במדור — לפי הפורמט המחייב לבקשות ייצור (נוהל יוסי, 16/06/26).

**אפס תלויות:** Python 3 stdlib + SQLite + פרונט וניל. בנויה לרשת פנימית — בלי pip, בלי npm, בלי CDN.

## הרצה

```bash
python3 server.py          # http://localhost:8342
python3 seed.py            # (אופציונלי) טעינת בקשות דוגמה
python3 -m unittest        # בדיקות
```

הנתונים נשמרים ב-`factory.db` ליד השרת. גיבוי = העתקת הקובץ.

## מה יש בפנים

הממשק **בנוי קודם לטלפון** (כי שם ההודעות ממילא נמצאות) בערכת "חמ"ל" כהה; במסך רחב הוא נערם לעמודה מרכזית. סקיצות הכיוונים שנבחנו: [design/](design/).

- **תור עבודות** — פיד ממוין לפי דחיפות תג"ב, צ'יפים שהם גם מדדים וגם מסננים, חיפוש חופשי, הדגשת חריגות
- **אכיפת שלמות** — בקשה עם שדות חובה חסרים נקלטת כ"מעוכבת" עם רשימת חוסרים
- **מחזור חיים** — מעוכבת → ממתינה לאישור → מאושרת → בייצור → הושלמה (+ נדחתה/בוטלה)
- **היסטוריה** — כל שינוי נרשם, כולל סימון מיוחד לשינוי מהותי אחרי אישור בקר
- **ייצוא חזרה ל-WhatsApp** — כפתור העתקה בפורמט המחייב

התכנון המלא, ממצאי ה-blindspot pass וה-unknown unknowns: [architecture.md](architecture.md)
